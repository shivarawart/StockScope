# StockScope 📈

**Understand the numbers. Make informed decisions.**

StockScope is a stock investment projection analyzer that helps users estimate potential investment growth, profit, and returns over time.

## ✨ Features

- 📊 Investment growth charts
- 💰 Initial investment and monthly contributions
- 📅 Investment duration and expected annual returns
- 📉 Profit, loss, and ROI calculations
- 🧮 Inflation and fee adjustments
- 🔍 Multiple investment scenarios
- 📋 Year-by-year breakdown
- 📥 Export projections to CSV
- 📱 Responsive UI

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- Chart.js

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/StockScope.git
```

### 2. Open the project

```bash
cd StockScope
```

### 3. Run the project

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in VS Code for a local development server.

## 💡 How It Works

1. Enter your initial investment.
2. Set your monthly contribution.
3. Choose your investment duration.
4. Adjust the expected annual return.
5. View estimated portfolio growth, profit, and ROI.
6. Compare scenarios and export your results.
